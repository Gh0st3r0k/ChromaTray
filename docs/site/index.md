# Pick a pixel. Find your palette.

ChromaTray is a Windows tray app for picking exact screen colors and extracting palettes from a selected region. It runs locally, with no account or service credentials.

<div class="feature-grid">
<div class="feature-card">
<h2>Precision picking</h2>
<p>A frozen desktop, an 11 × 11 pixel magnifier, and arrow-key adjustments in physical pixels.</p>
</div>
<div class="feature-card">
<h2>Useful palettes</h2>
<p>Rank region colors by frequency, inspect five color formats, and copy text, CSS, or JSON.</p>
</div>
<div class="feature-card">
<h2>Code-connected reference</h2>
<p>API pages are generated from the C# project and its English XML comments on every documentation build.</p>
</div>
</div>
