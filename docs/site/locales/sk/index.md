# Vyber pixel. Nájdi svoju paletu.

ChromaTray je aplikácia pre oznamovaciu oblasť systému Windows na výber presných farieb obrazovky a získavanie paliet z vybranej oblasti. Funguje lokálne, bez účtu a prihlasovania do služieb.

<div class="feature-grid">
<div class="feature-card">
<h2>Presný výber</h2>
<p>Snímka pracovnej plochy, lupa s rozmermi 11 × 11 pixelov a posúvanie šípkami po jednotlivých fyzických pixeloch.</p>
</div>
<div class="feature-card">
<h2>Užitočné palety</h2>
<p>Zoradenie farieb podľa početnosti, päť farebných formátov a kopírovanie do textu, CSS alebo JSON.</p>
</div>
<div class="feature-card">
<h2>Referencia z kódu</h2>
<p>DocFX pri každom zostavení vytvára stránky API z projektu C# a jeho anglických XML komentárov.</p>
</div>
</div>
