# Справочник API

Эти страницы создаются непосредственно из проекта C#. Описания берутся из **английских XML-комментариев**; сигнатуры, параметры, возвращаемые типы и ссылки на исходники соответствуют коду. Навигация и подписи интерфейса переведены.

| --- | --- |
| [Модели](xref:ChromaTray.Models) | [ColorDetails](xref:ChromaTray.Models.ColorDetails), [AppSettings](xref:ChromaTray.Models.AppSettings), [HotkeyBinding](xref:ChromaTray.Models.HotkeyBinding) |
| [Сервисы](xref:ChromaTray.Services) | [PaletteAnalyzer](xref:ChromaTray.Services.PaletteAnalyzer), [PaletteExporter](xref:ChromaTray.Services.PaletteExporter), [SettingsValidator](xref:ChromaTray.Services.SettingsValidator) |
| [Окна](xref:ChromaTray.Forms) | [MainDashboardForm](xref:ChromaTray.Forms.MainDashboardForm), [ScreenOverlayForm](xref:ChromaTray.Forms.ScreenOverlayForm), [SettingsForm](xref:ChromaTray.Forms.SettingsForm) |

Справочник охватывает публичный API. [Обзор разработки](../development.md) объясняет внутренние элементы управления и этапы захвата экрана.
