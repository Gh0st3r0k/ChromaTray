# Начало работы

## Запуск приложения

Используйте сборку для Windows x64 из доверенного источника или соберите проект самостоятельно. Автономная сборка включает .NET; облегчённая требует .NET 8 Desktop Runtime x64.

Для запуска из исходников в Windows установите .NET 8 SDK и выполните команды из корня репозитория:

```powershell
dotnet restore ChromaTray.csproj --locked-mode
dotnet run --project ChromaTray.csproj -c Release --no-restore
```

Перед обновлением или сборкой выберите **Exit** в меню трея. Крестик скрывает окно, но процесс продолжает блокировать EXE. Сворачивание через панель задач и скрытие в трей — разные действия; оба сохраняют текущую палитру.

## Выбор цветов

| Действие | Управление |
| --- | --- |
| Выбрать точку | `Ctrl+Shift+X` или **Pick Point** |
| Сдвинуть выбор | Стрелки, по одному физическому пикселю |
| Подтвердить точку | `Enter` или левая кнопка мыши |
| Сканировать область | `Ctrl+Shift+Z` или **Scan Region**, затем выделение мышью |
| Отменить | `Esc` или правая кнопка мыши |
| Скопировать выбранный цвет | Двойной щелчок или `Ctrl+C` |
| Изменить горячие клавиши и форматы | **Settings** |
| Полностью закрыть приложение | Меню в трее → **Exit** |

Перед снимком рабочего стола приложение скрывает своё окно. Выбор точки всегда возвращает исходный RGB-пиксель. ClearType и другие способы сглаживания могут создавать цветные пиксели по краям букв: они уже присутствуют на экране и видны в лупе.

## Просмотр и экспорт

Выберите строку палитры, чтобы обновить сведения о цвете. В узком окне используйте вкладки **Palette** и **Inspector**. В списке экспорта доступны активные форматы, основной формат, CSS-переменные и JSON.

Переключатель **Group similar shades** находится под заголовком палитры и в настройках. По умолчанию он выключен. При включении каждую группу RGB представляет её самый частый исходный цвет; количество пикселей суммируется для всех оттенков группы. В списке отображается до 500 записей, а проценты рассчитываются от всей захваченной области.
