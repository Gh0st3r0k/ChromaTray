# Выбери пиксель. Найди свою палитру.

ChromaTray — приложение для системного трея Windows, которое определяет точные цвета экранных пикселей и собирает палитру выбранной области. Оно работает локально, без учётной записи и подключения к сервисам.

<div class="feature-grid">
<div class="feature-card">
<h2>Точный выбор</h2>
<p>Снимок рабочего стола, лупа 11 × 11 пикселей и перемещение стрелками с шагом в один физический пиксель.</p>
</div>
<div class="feature-card">
<h2>Удобные палитры</h2>
<p>Сортировка цветов по частоте, пять цветовых форматов и копирование в текст, CSS или JSON.</p>
</div>
<div class="feature-card">
<h2>Справочник из кода</h2>
<p>При каждой сборке DocFX создаёт страницы API из проекта C# и его английских XML-комментариев.</p>
</div>
</div>

## Кратко о проекте

| Платформа | Среда выполнения | Горячие клавиши по умолчанию | Лицензия |
| --- | --- | --- | --- |
| Windows 10/11, x64 | .NET 8 Windows Desktop | Точка: `Ctrl+Shift+X` · Область: `Ctrl+Shift+Z` | MIT |

Руководства доступны на **английском, словацком, чешском, русском и украинском**. Переключение языка сохраняет открытую страницу. Описания API создаются из английских XML-комментариев; имена и сигнатуры соответствуют коду.
