# Plány rozvoje

Nápady pro budoucí verze. Seznam se může měnit a nepředstavuje závazek k termínům.

## Motivy vzhledu

Přidat světlý a tmavý motiv a poté zvážit vlastní barvy rozhraní. Zachovat čitelný text, přístupný kontrast a jednotný vzhled okna, nastavení, nabídek a výběru barev.

## Windows, Linux a macOS

Prozkoumat náhradu Windows Forms multiplatformním rozhraním, například Avalonia se zachováním C#. Znovu využít barevné algoritmy, export a vhodné testy. Snímání obrazovky, globální klávesové zkratky, oznamovací oblast a oprávnění OS vyžadují samostatné implementace a ověření pro každou platformu.

## Možná změna jazyka

Vyhodnotit jiné jazyky a technologie na malém prototypu. O přepsání rozhodnout až po porovnání rychlosti spuštění a obnovení okna, spotřeby paměti a náročnosti vývoje. Samotná změna jazyka nezaručuje vyšší výkon ani podporu více OS.

## Palety pro webdesign

Vytvořit pět sladěných barev na základě vybrané barvy, umožnit uzamčení jednotlivých barev a nové generování ostatních. Zobrazit výsledek na ukázkovém webu, ověřovat kontrast textu a tlačítek a exportovat proměnné CSS. Jde o celé designové palety, nejen světlejší či tmavší odstíny jedné barvy. Před výběrem implementace vyhodnotit online generátory a otevřené alternativy.
