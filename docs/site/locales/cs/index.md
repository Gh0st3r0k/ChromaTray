# Vyber pixel. Najdi svou paletu.

ChromaTray je aplikace pro oznamovací oblast systému Windows, která vybírá přesné barvy obrazovky a získává palety z vybrané oblasti. Funguje místně, bez účtu a přihlašování ke službám.

<div class="feature-grid">
<div class="feature-card">
<h2>Přesný výběr</h2>
<p>Snímek pracovní plochy, lupa o velikosti 11 × 11 pixelů a posouvání šipkami po jednotlivých fyzických pixelech.</p>
</div>
<div class="feature-card">
<h2>Užitečné palety</h2>
<p>Řazení barev podle četnosti, pět barevných formátů a kopírování do textu, CSS nebo JSON.</p>
</div>
<div class="feature-card">
<h2>Reference z kódu</h2>
<p>DocFX při každém sestavení vytváří stránky API z projektu C# a jeho anglických XML komentářů.</p>
</div>
</div>
