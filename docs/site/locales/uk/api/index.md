# Довідник API

Ці сторінки створюються безпосередньо з проєкту C#. Описи беруться з **англійських XML-коментарів**; сигнатури, параметри, типи результатів і посилання на вихідний код відповідають коду. Навігацію та підписи інтерфейсу перекладено.

| Простір імен | З чого почати |
| --- | --- |
| [Моделі](xref:ChromaTray.Models) | [ColorDetails](xref:ChromaTray.Models.ColorDetails), [AppSettings](xref:ChromaTray.Models.AppSettings), [HotkeyBinding](xref:ChromaTray.Models.HotkeyBinding) |
| [Сервіси](xref:ChromaTray.Services) | [PaletteAnalyzer](xref:ChromaTray.Services.PaletteAnalyzer), [PaletteExporter](xref:ChromaTray.Services.PaletteExporter), [SettingsValidator](xref:ChromaTray.Services.SettingsValidator) |
| [Вікна](xref:ChromaTray.Forms) | [MainDashboardForm](xref:ChromaTray.Forms.MainDashboardForm), [ScreenOverlayForm](xref:ChromaTray.Forms.ScreenOverlayForm), [SettingsForm](xref:ChromaTray.Forms.SettingsForm) |

Довідник охоплює публічний API. [Огляд розробки](../development.md) пояснює внутрішні елементи керування й етапи захоплення екрана.
