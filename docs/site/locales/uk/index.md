# Вибери піксель. Знайди свою палітру.

ChromaTray — застосунок для системного трея Windows, який визначає точні кольори екранних пікселів і створює палітру вибраної області. Він працює локально, без облікового запису та підключення до сервісів.

<div class="feature-grid">
<div class="feature-card">
<h2>Точний вибір</h2>
<p>Знімок робочого стола, лупа 11 × 11 пікселів і переміщення стрілками з кроком в один фізичний піксель.</p>
</div>
<div class="feature-card">
<h2>Зручні палітри</h2>
<p>Сортування кольорів за частотою, п’ять колірних форматів і копіювання в текст, CSS або JSON.</p>
</div>
<div class="feature-card">
<h2>Довідник із коду</h2>
<p>Під час кожної збірки DocFX створює сторінки API з проєкту C# та його англійських XML-коментарів.</p>
</div>
</div>

## Про проєкт

| Платформа | Середовище виконання | Типові гарячі клавіші | Ліцензія |
| --- | --- | --- | --- |
| Windows 10/11, x64 | .NET 8 Windows Desktop | Точка: `Ctrl+Shift+X` · Область: `Ctrl+Shift+Z` | MIT |

Посібники доступні **англійською, словацькою, чеською, російською та українською**. Перемикання мови зберігає поточну сторінку. Описи API створюються з англійських XML-коментарів; назви й сигнатури відповідають коду.
