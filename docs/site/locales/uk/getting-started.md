# Початок роботи

## Запуск застосунку

Використовуйте збірку для Windows x64 із надійного джерела або зберіть проєкт самостійно. Автономна збірка містить .NET; полегшена потребує .NET 8 Desktop Runtime x64.

Для запуску з вихідного коду у Windows установіть .NET 8 SDK і виконайте команди з кореня репозиторію:

```powershell
dotnet restore ChromaTray.csproj --locked-mode
dotnet run --project ChromaTray.csproj -c Release --no-restore
```

Перед оновленням або збиранням виберіть **Exit** у меню трея. Хрестик приховує вікно, але процес продовжує блокувати EXE. Згортання через панель завдань і приховування в трей — різні дії; обидві зберігають поточну палітру.

## Вибір кольорів

| Дія | Керування |
| --- | --- |
| Вибрати точку | `Ctrl+Shift+X` або **Pick Point** |
| Зсунути вибір | Стрілки, по одному фізичному пікселю |
| Підтвердити точку | `Enter` або ліва кнопка миші |
| Сканувати область | `Ctrl+Shift+Z` або **Scan Region**, потім виділення мишею |
| Скасувати | `Esc` або права кнопка миші |
| Скопіювати вибраний колір | Подвійне клацання або `Ctrl+C` |
| Змінити гарячі клавіші та формати | **Settings** |
| Повністю закрити застосунок | Меню в треї → **Exit** |

Перед знімком робочого стола застосунок приховує своє вікно. Вибір точки завжди повертає початковий RGB-піксель. ClearType та інші способи згладжування можуть створювати кольорові пікселі на краях літер: вони вже є на екрані та відображаються в лупі.

## Перегляд та експорт

Виберіть рядок палітри, щоб оновити відомості про колір. У вузькому вікні використовуйте вкладки **Palette** та **Inspector**. У списку експорту доступні активні формати, основний формат, CSS-змінні та JSON.

Перемикач **Group similar shades** розміщений під заголовком палітри та в налаштуваннях. Типово він вимкнений. Коли його ввімкнено, кожну RGB-групу представляє її найчастіший початковий колір; кількість пікселів підсумовується для всіх відтінків групи. Список містить до 500 записів, а відсотки розраховуються від усієї захопленої області.
