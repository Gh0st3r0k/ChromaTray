# Плани розвитку

Ідеї для майбутніх версій. Перелік може змінюватися й не передбачає зобов’язань щодо термінів.

## Теми оформлення

Додати світлу й темну теми, а потім розглянути власні кольори інтерфейсу. Зберегти читабельність тексту, доступний контраст і узгоджене оформлення вікна, налаштувань, меню та вибору кольору.

## Windows, Linux і macOS

Дослідити заміну Windows Forms кросплатформним інтерфейсом, наприклад Avalonia зі збереженням C#. Повторно використати алгоритми кольорів, експорт і придатні тести. Захоплення екрана, глобальні сполучення клавіш, трей і дозволи ОС потребуватимуть окремих реалізацій та перевірок для кожної платформи.

## Можлива зміна мови

Оцінити інші мови й технології на невеликому прототипі. Рішення про переписування ухвалювати після порівняння швидкості запуску й відновлення вікна, споживання пам’яті та зручності розробки. Сама зміна мови не гарантує прискорення або підтримки кількох ОС.

## Палітри для вебдизайну

Добирати п’ять узгоджених кольорів на основі вибраного, закріплювати окремі кольори й генерувати решту заново. Показувати результат на макеті сайту, перевіряти контраст тексту та кнопок, експортувати CSS-змінні. Це повноцінні дизайнерські палітри, а не лише світлі чи темні відтінки одного кольору. Перед вибором реалізації оцінити онлайн-генератори та відкриті альтернативи.

### Джерела палітр і особисті ключі

Запланувати налаштування **«Джерело палітр»**. Перший кандидат — Colormind: опубліковані приклади API не потребують облікового запису чи ключа. Для інших провайдерів передбачити особистий API-ключ, якщо сервіс його підтримує; запити враховуватимуться за обліковим записом і умовами користувача. Не вимагати ключ для сервісів, які його не використовують.

Надсилати запити лише за явною дією користувача й передавати вибрані RGB-кольори, а не знімки екрана. Особисті ключі зберігати в захищеному сховищі ОС, а не у звичайному `settings.json`; передбачити видалення та виключити ключі з журналів і експорту.

Опубліковані умови Colormind дозволяють безкоштовне особисте й некомерційне використання API; для комерційного застосунку потрібно звернутися до власника сервісу. Ліцензія MIT ChromaTray не надає додаткових прав на сторонні API. Зазначити ці окремі умови в документації. Перед інтеграцією перевірити HTTPS та актуальні умови сервісу. Закріплені кольори зберігати точно на боці застосунку: Colormind може трохи змінювати вхідні кольори.

Це план: вибір провайдера та зберігання ключів поки не реалізовані.
