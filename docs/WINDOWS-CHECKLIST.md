# Ручная проверка на Windows

Выполняется на Windows 10/11 x64 с обычным рабочим столом. Это список проверок перед релизом; отметки ниже не означают, что они уже пройдены.

- [ ] Откройте приложение: видны панель, иконка в трее, форматы и пример цвета `#3B82F6`.
- [ ] Нажмите X: окно скрывается; щелчок по иконке возвращает панель.
- [ ] Второй экземпляр сообщает, что ChromaTray уже запущен.
- [ ] **Ctrl+Shift+X** открывает захват без панели на снимке; лупа показывает правильный пиксель. Выберите цвет и проверьте его вставкой в Блокнот.
- [ ] Откройте пипетку из скрытого приложения и отмените через Esc/правую кнопку: панель не должна неожиданно появиться.
- [ ] На белом и чёрном фоне проверьте RGB/HEX и читаемость лупы у всех краёв монитора.
- [ ] На втором мониторе, включая расположенный слева/выше основного, проверьте отрицательные координаты, соответствие пикселю и видимость лупы/подсказки.
- [ ] Если есть экраны с масштабом 100%/150%/200%, проверьте геометрию выделения и лупы на каждом из них.
- [ ] **Ctrl+Shift+Z**: выделите область в каждом направлении; доли цветов и число пикселей соответствуют области.
- [ ] Проверьте захват области через границу двух экранов и отмену слишком маленького выделения.
- [ ] Переключите **Group similar shades** несколько раз: последняя область пересчитывается, итог соответствует последнему состоянию переключателя.
- [ ] Начните новый захват, пока идёт анализ предыдущего: старый результат не должен заменять новый.
- [ ] В Settings задайте разные хоткеи; проверьте их после сохранения и перезапуска.
- [ ] Назначьте занятый другой программой хоткей: панель показывает предупреждение, кнопки продолжают работать.
- [ ] Оставьте только RGB; пипетка копирует RGB, таблица и карточка показывают только RGB. Нельзя снять последний формат.
- [ ] Проверьте Copy у форматов, двойной щелчок по строке, Copy Active Formats и четыре режима Copy Entire Palette.
- [ ] При основном HSV/CMYK CSS-экспорт содержит HEX, а JSON сохраняет выбранные форматы и числовые проценты.
- [ ] Измените размер окна до минимального; проверьте доступность кнопок и прокрутки таблицы при высоком DPI.
- [ ] Выполните **Exit**: иконка исчезает, процесс завершается, повторный запуск работает.
- [ ] Запустите standalone на машине без .NET и lightweight на машине с Desktop Runtime 8 x64.

Для отчёта о проблеме укажите версию Windows, масштаб и расположение мониторов, команду сборки, действие и фактический результат. Не прикладывайте снимки с личными данными.
